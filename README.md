# Yang Song - Portfolio Website

A professional portfolio website showcasing Yang Song's experience in autonomous driving, robotics research, and big data engineering.

## 🚀 Features

- **Responsive Design**: Modern, clean interface that works on all devices
- **Multilingual Support**: English and German language options
- **Interactive Navigation**: Smooth scrolling and hover effects
- **Professional Sections**: 
  - Autonomous Driving experience
  - Robotic Research publications
  - Startup Experience (Auro Robotics)
  - Big Data engineering work

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: Node.js with Express.js
- **Styling**: Custom CSS with modern design principles
- **Deployment**: GitHub Pages

## 📁 Project Structure

```
ysonggit.github.io/
├── public/           # Static files served by Express
│   ├── works/       # Individual work pages
│   ├── css/         # Stylesheets
│   ├── js/          # JavaScript files
│   └── assets/      # Images and media
├── works/           # Source files for work pages
├── server.js        # Express server for local development
└── package.json     # Node.js dependencies
```

## 🚀 Local Development

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start the development server**:
   ```bash
   npm start
   ```

3. **Access the website**:
   Open `http://localhost:3000` in your browser
